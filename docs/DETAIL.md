# 小深 · 桌面助手

一枚白色小胶囊停在桌面上，点一下就能和 DeepSeek 聊天。浮在所有 App 之上（包括全屏 App），
关掉 DeepSeek Harness 后它照样在。

## 打开 / 关闭

- 左侧栏 **桌面助手** → 点「打开」或「关闭」
- 或者在对话框里输入：`/pet open`、`/pet close`、`/pet status`、`/pet`（开关切换）
- 也可以右键胶囊 →「退出小深」

## 要求

macOS，带 Tk 8.6 的 Python 3（不需要装任何 Python 包），DeepSeek Harness 已登录。
python3 不在常见位置时，设置环境变量 `DSH_PET_PYTHON` 指到它。
