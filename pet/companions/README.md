# 小深的伙伴

伙伴是站在胶囊左边的像素小角色。**一个伙伴 = 一张 PNG 像素图**，文件名（去掉 `.png`）就是它的 id。

- 内置伙伴：这个文件夹（`pet/companions/`）。
- **自己画的伙伴放 `~/.dsh-pet/companions/`**：插件更新不会覆盖它；和内置的同名时，用你的。

放进去以后，在 DeepSeek Harness 左侧栏「桌面助手」→「我的伙伴」里就能看到并选用。
正在使用的伙伴，PNG 改完保存，桌面上的小深大约 1 秒内就会换上。

## 怎么画

- 用任何像素画工具都行：[Piskel](https://www.piskelapp.com/)（网页版，免费）、Aseprite、Photoshop……
- **背景要透明**，导出 PNG。
- 推荐画布 **16×16 到 24×24 像素**。小深会按整数倍放大到大约 46 像素高，保持像素锐利：
  16 像素高 → 放大 3 倍，24 像素高 → 放大 2 倍。
- 最大显示 84×64 像素；更大的图会被抽样缩小，细节会丢，所以别画太大。
- 半透明像素按不透明处理（小深的窗口没法画半透明）。

## 名字和介绍（可选）

在 PNG 旁边放一个同名的 `.json`：

```json
{
  "name": "橘子",
  "author": "你的名字",
  "description": "一只圆滚滚的橘猫，陪你摸鱼也陪你加班。"
}
```

没有这个文件时，名字就用文件名。

## 它会做什么

- 站在胶囊左边，脚踩胶囊的底边。
- 小深思考的时候，它会上下轻轻跳。
- 点它 = 开始新聊天；按住它也能拖动小深。
